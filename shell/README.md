# Shell

| Directory | What it is |
| --------- | ---------- |
| `bingux/` | The shell itself: QML, its Python helpers and its icons. |
| `runtime/` | `bingux-shell`: Quickshell with the Bingux patches built into one binary. See its README. |
| `quickshell-patches/` | The patches applied to Quickshell. |
| `qmltermwidget/` | Patches and the Bingux colour scheme for the QMLTermWidget plugin that the shell's terminal uses. |
