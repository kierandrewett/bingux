# Product

## Register

product

## Users

Kieran uses Bingux as a daily desktop shell, with keyboard and pointer input across multiple windows.

## Product Purpose

Provide a coherent desktop with a top bar, dock, menus, notifications and a resizable edge sidebar. Keep frequently used tools available without covering working windows.

## Brand Personality

Quiet, compact and consistent with the existing shell primitives.

## Anti-references

Avoid mismatched native tooltips, excessive nested padding, overflowing controls and focus changes that make interactions unpredictable.

## Design Principles

- Use the shared shell controls and theme.
- Preserve running sessions and the user's chosen dimensions.
- Keep actions predictable across mouse and keyboard input.
- Give content room while keeping chrome compact.

## Accessibility & Inclusion

Keep keyboard navigation, accessible control names, readable contrast and reduced-motion behaviour supported by the existing shell.
